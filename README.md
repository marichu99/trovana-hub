# Trovana Hub

Portfolio website for Trovana Hub — a studio offering website development and digital advertising for businesses.

## Stack

Static HTML/CSS/JS, no build step.

## Structure

- `index.html` — single-page site (hero, services, work, about, contact)
- `css/style.css` — gold-and-black theme
- `js/script.js` — mobile nav + contact form (mailto)
- `assets/` — favicon and static assets

## Local preview

Open `index.html` directly in a browser, or serve it:

```
python3 -m http.server 8000
```

## Deployment

Deployed via GitHub Pages from the `main` branch.
